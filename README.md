# 碎语 Chatter

一个把短文字留在浏览器本地的极简信息流。纯 HTML + CSS + JavaScript 编写，零依赖、零构建、零后端。

## 功能

- 发布短文字：输入框 + 发布按钮，实时字数统计（上限 280 字），空白内容不可发布
- 查看信息流：新内容置顶，显示头像、昵称、相对时间与正文
- 删除单条：确认后移除，本地数据同步更新
- 本地持久化：所有内容保存在浏览器 Local Storage，刷新或重新打开页面后依然存在
- 键盘操作：`Ctrl` / `Cmd` + `Enter` 快速发布
- 响应式布局：桌面与移动端均可正常使用

## 运行方式

方式一：直接双击 `index.html`，用浏览器打开即可。

方式二：启动一个本地静态服务后访问（推荐，便于调试）：

```bash
python -m http.server 8765
# 打开 http://localhost:8765/
```

## 数据说明

- 存储位置：浏览器 `localStorage`，键名 `chatter.posts.v1`
- 数据结构：`{ id, text, createdAt }` 组成的 JSON 数组，按时间倒序
- 清除浏览器站点数据会一并清空所有内容；浏览器禁用本地存储时会自动降级为内存模式（当次页面有效）

## 目录结构

```
mini-feed/
├── index.html   # 页面骨架：顶栏、发布卡、信息流、空状态
├── style.css    # 深色主题、卡片信息流、入场动效与响应式
├── app.js       # 存储层、发布/删除、安全渲染
└── README.md
```

## 技术要点

- 无框架、无包管理器、无网络请求，可离线使用
- 用户文本通过 `textContent` 渲染，不使用 `innerHTML` 拼接，避免 XSS
- `localStorage` 读写全部包裹异常处理，脏数据自动降级为空列表
- 中文输入法组合输入（composition）期间不会触发快捷键误发布
